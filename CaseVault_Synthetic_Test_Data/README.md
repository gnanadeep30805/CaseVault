# CaseVault Synthetic Test Data

Synthetic, non-real data for full-system testing.

Use it to test:
- Authentication, MFA, RBAC and ABAC
- Cases and case membership
- Documents, upload/download/preview/versioning/approval
- Evidence and chain of custody
- Police asset lifecycle
- Audit trail and hash-chain verification
- Search/OCR/RAG ingestion
- Integrity/tamper detection
- Notifications and dashboards
- Light/dark UI and route coverage

All identifiers and records are fictional.
